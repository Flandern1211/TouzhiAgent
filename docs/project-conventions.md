# 项目约定

这些约定覆盖 v1 已实现的项目边界；新增行为仍需先更新需求和技术设计。

## 代码

- v1 代码使用 Python。
- 本机服务使用 FastAPI/Uvicorn，核心分析保持为可独立测试的 Python 服务。
- 每个代码包只围绕一个已确认的产品边界演进，跨边界调用通过明确的数据对象或接口完成。
- 不在业务代码中写死爬虫 API、数据库地址、账号或密钥。
- 对外部数据和 Agent 输出保留状态信息，不用空值掩盖缺失、过期或失败。

## 数据与证据

- 重要数据保留来源标识、抓取时间、有效时间（如有）和原文链接或等价引用。
- 正式净值、盘中估算、新闻/公告事实、Agent 推断和社交媒体线索必须可区分。
- 来源冲突必须显式记录，不能静默覆盖。

## 测试

- 纯规则和指标计算应可脱离网络独立测试。
- 外部爬虫、远程 MySQL 和模型调用不应成为单元测试的隐式依赖。
- 对来源失败、数据过期、证据不足和份额类别识别错误保留测试场景。

## 需求与变更

- 需求变更先更新 `docs/requirements/`，再决定是否需要技术设计、UI 设计或 API 文档。
- 未确认的功能不得通过占位代码或默认配置悄悄启用。
- v1 不加入交易执行、账户导入或外部推送。
